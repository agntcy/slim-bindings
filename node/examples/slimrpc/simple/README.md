# SlimRPC Simple Example (Node.js / TypeScript)

Demonstrates all four slimrpc RPC shapes — plus the multicast/group client —
against a running SLIM broker, using code generated by
`protoc-gen-slimrpc-node` and message types from `protoc-gen-es`.

## Prerequisites

- Node.js ≥ 18
- A running SLIM broker on `localhost:46357`
- `buf` CLI (for regenerating), and `protoc-gen-slimrpc-node` on `PATH`
  (`cargo install --locked agntcy-protoc-slimrpc-plugin --bin protoc-gen-slimrpc-node`)

The broker can be any SLIM server. For local development you can use the
Node.js example server, which runs an in-process SLIM node:

```bash
cd ../..            # node/examples
npx tsx server.ts   # listens on 0.0.0.0:46357
```

## Install & generate

```bash
npm install
# from the node/ directory:
task generate-proto   # or: run `buf generate` in this folder
```

`buf generate` produces, under `types/`:

- `example_pb.ts` — protobuf-es message types + schemas.
- `example_slimrpc.ts` — slimrpc `TestClient`, `TestGroupClient`,
  `TestServicer`, handler adapters, and `registerTestServicer`.

> The checked-in `buf.gen.yaml` passes
> `bindings_import=../../../../generated/index.js` so the generated stubs use
> the locally built bindings. Downstream projects should drop that option to use
> the published `@agntcy/slim-bindings` package.

## Run

Point-to-point (one server):

```bash
# terminal 1
npm run server
# terminal 2
npm run client
```

Multicast / group (multiple servers):

```bash
# terminal 1
npm run server -- --instance server1
# terminal 2
npm run server -- --instance server2
# terminal 3
npm run client-group -- --servers server1,server2
```

Each command accepts `--help`.

## Code structure

### Server (`server.ts`)

Implements `TestServicer`:

- **ExampleUnaryUnary** — request → response
- **ExampleUnaryStream** — request → `AsyncIterable` of responses
- **ExampleStreamUnary** — `AsyncIterable` of requests → response
- **ExampleStreamStream** — `AsyncIterable` of requests → `AsyncIterable` of responses

and registers it with `registerTestServicer(server, new TestService())`.

### Point-to-point client (`client.ts`)

```ts
const client = new TestClient(channel);
const reply = await client.ExampleUnaryUnary(request, 5000);
for await (const resp of client.ExampleUnaryStream(request, 5000)) { /* ... */ }
const agg = await client.ExampleStreamUnary(streamRequests(), 5000);
for await (const resp of client.ExampleStreamStream(streamRequests(), 5000)) { /* ... */ }
```

### Group client (`client_group.ts`)

```ts
const group = new TestGroupClient(channel);
for await (const { context, response } of group.ExampleUnaryUnary(request, 5000)) {
  console.log(context.source, response);
}
```

Each group method yields one `{ context, response }` per responding member.

## Notes

- Messages are constructed with protobuf-es `create(Schema, { ... })`; note
  `int64` fields are `bigint` (e.g. `exampleInteger: 1n`).
- Timeouts are plain milliseconds (`number`); metadata is `Map<string, string>`.
- Throw `new RpcError.Rpc({ code, message, details })` from a servicer method to
  return a specific status; other errors become `RpcCode.Internal`.

See [../../../SLIMRPC.md](../../../SLIMRPC.md) for the full generator reference.
