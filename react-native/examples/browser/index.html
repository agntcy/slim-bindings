Group workflow

Open participant one and participant two, click Start in both tabs, then start the moderator. Messages and the participant list update in every tab. For MLS, use the MLS example pages — the moderator enables encryption and participants inherit it automatically.

Configuration

Override defaults with query parameters, for example ?local=org/alice/app&server=ws://127.0.0.1:46357. See the README for the full parameter list for each agent role.
