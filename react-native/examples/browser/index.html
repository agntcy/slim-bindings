SLIM · WebAssembly · WebSocket

Browser reference examples

Focused implementations that mirror the Node.js examples in slim-bindings/node/examples/. Each page runs one role with defaults you can override through query parameters.

Point-to-point

  • Point-to-point Alice (receiver)

    Listens for incoming sessions and replies to each message.

  • Point-to-point Bob (sender)

    Creates a session with a remote peer and sends messages.

Group messaging

  • Group moderator

    Creates a multicast session and invites participants.

  • Group participant

    Waits for a group invitation and exchanges messages.

Configuration

Append query parameters to override defaults, for example ?local=org/alice/app&server=ws://127.0.0.1:46357. See each example’s README section for the full parameter list.
